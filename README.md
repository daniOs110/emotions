# Siento

Web app (React + Vite + TypeScript) that helps you name what you feel through short guided questions and an emotion circle — then offers simple recommendations. Spanish and English. Check-ins stay in your browser (`localStorage`).

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## What it includes

- Guided quiz (energy, valence, body, impulse, context, need) with tie-break
- Interactive emotion circle (family → secondary → specific)
- Result screen with short tips
- Local check-in history
- ES / EN toggle

Siento orients; it does not replace professional support.
